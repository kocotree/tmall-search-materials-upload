# 自动化上传搜推素材 skill

## 项目基本信息

- 项目名称：自动化上传搜推素材 skill
- 对接人：蛤蜊
- 负责人：AI 实习生
- 当前阶段：项目启动 / 人工流程拆解

## 项目目标

把蛤蜊当前的人工上传搜推素材动作，拆成一个可复用、可校验、可追踪的 skill。

第一版不追求全自动，先做到：

读取素材清单 → 校验素材 → 生成上传任务 → 辅助上传/半自动执行 → 输出成功失败报告。

## 当前需要澄清的问题

1. 现在上传搜推素材完整步骤是什么？
2. 素材从哪里来？本地、飞书、NAS、表格，还是其他系统？
3. 上传到哪里？后台入口是什么？
4. 文件命名有没有规则？
5. 一次通常上传多少商品、多少素材？
6. 上传前要检查什么？
7. 上传成功后怎么确认？
8. 失败时现在怎么处理？
9. 哪些步骤可以自动化？
10. 哪些步骤必须人工确认？

## MVP 边界

### 第一版要做

- 读取素材清单。
- 校验素材是否存在、命名是否符合规则。
- 校验商品 ID、链接、负责人等关键信息是否齐全。
- 生成上传任务清单。
- 辅助执行上传或生成可操作步骤。
- 输出成功/失败报告。

### 第一版暂不做

- 不自动删除素材。
- 不自动覆盖旧素材。
- 不自动改商品信息。
- 不绕过人工确认直接发布。
- 不在失败时静默重试很多次。

## 风险点

- 素材命名不统一。
- 商品 ID 或链接错配。
- 上传入口或后台规则变化。
- 重复上传、覆盖旧素材。
- 上传失败后没有清晰记录。

## 验收标准

- 能说清楚人工流程。
- 能跑通一批真实样例。
- 每个任务有状态：待上传、成功、失败、需人工确认。
- 失败原因能被记录。
- 蛤蜊能看懂并确认流程有用。
