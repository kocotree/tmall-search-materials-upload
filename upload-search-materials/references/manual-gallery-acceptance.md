# 第三阶段人工验收清单

以下复杂交互由用户在真实 NAS / RaiDrive 环境验收，自动化测试不代替这些步骤。

1. 进入第三阶段时，候选文件夹立即出现；每张卡片先显示“素材数统计中”，随后变成原始递归素材数或“素材数未知”。
2. 确认父子文件夹同时出现时，理解原始递归计数可能重叠；这不是最终候选数。
3. 在文件夹列表下方、候选图片区上方点击“确认文件夹并加载图片”。确认此时没有 Codex handoff、没有 Agent 租约，也不需要在聊天回复“已提交”。
4. 长时间加载期间检查进度是否分别显示发现路径、检查 X/Y、失败、内容重复、最终候选和待处理。
5. 加载完成后确认最终消息替换运行中消息；例如检查 300、重复 14 时应显示最终候选 286，而不是“已准备 284”。
6. 刷新页面，确认完成数字和候选图片保持一致，不恢复旧的运行消息。
7. 中断页面服务或断开 NAS 后恢复，确认失败显示“素材数未知”或稳定 gallery job 原因，并可在页面重试。
8. 进入选图步骤后，确认页面底部只显示“确认选图并提交给 Codex”；只有点击该按钮才产生唯一的 `final_material_selection` handoff。
