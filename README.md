# 天猫搜推素材上新工作台

面向天猫部运营团队的 Windows 11 Codex Plugin。它通过本地工作台完成千牛搜推素材坑位巡检、团队素材索引匹配、人工选图、确定性坑位编排、标题与描述生成、上传确认、正式上传和飞书成功记录。

- Plugin ID：`tmall-search-materials`
- Marketplace：`tmall-materials-team`
- Windows 生产分支：`win`
- 用户使用说明：[上传搜推素材插件使用文档](docs/上传搜推素材插件使用文档/上传搜推素材插件使用文档.md)
- 开发与运维交接：[项目交接说明书](docs/项目交接说明书.md)
- 配套定时通知项目：[tmall-empty-slot-notifier](https://github.com/kocotree/tmall-empty-slot-notifier)

普通用户不需要克隆本仓库或手工安装 Python。请按照使用说明，通过 Codex Marketplace 安装 Plugin。
